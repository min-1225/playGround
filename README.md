# Playground 🧪

> A space for experiments, practice, and everything in between.

개발 과정에서 진행하는 다양한 실험과 학습 기록을 모아두는 공간입니다.

특정 기술이나 프로젝트에 얽매이지 않고, 새로운 개념을 익히거나 작은 아이디어를 구현하며 얻은 결과물을 자유롭게 기록합니다.

## Contents

- **Database** — SQL 쿼리, 데이터베이스 실습 및 ERD
- **Algorithms** — 간단한 알고리즘 구현과 문제 풀이 실험
- **Languages** — Java, Python, C 등 프로그래밍 언어 학습
- **Experiments** — 새로운 기술, 라이브러리 및 도구 테스트
- **Miscellaneous** — 개인적인 코드 조각과 기타 실습 자료

## Purpose

- 새로운 기술과 개념을 부담 없이 실험하기
- 학습 과정에서 작성한 코드를 기록하고 보관하기
- 작은 아이디어를 빠르게 구현해 보기
- 시행착오와 경험을 축적하기

Not everything here is meant to be a finished product.

Some experiments may remain unfinished, some may be rewritten, and some may simply exist for the sake of learning.

**Just build, break, learn, and repeat.**
